# kikko-images

@kikko_do（京都鍼灸きっこうどう）のThreads投稿に使う写真置き場です。

## カナコさんがやること

**`写真` フォルダに、写真を入れるだけです。**

- ファイル名は半角英数字にしてください（例：`shinshitsu.jpg`）
- 日本語のファイル名でも動きますが、半角のほうが確実です
- 入れたら「写真入れました」と言っていただければ、こちらで公開して投稿に組み込みます

## 置かないもの

このリポジトリは **Public（誰でも見られる）** です。

- 患者さんが写っている写真は入れないでください
- 投稿の原稿や記録は、`kanako-contact`（非公開）のほうに置いています

## 仕組み

Threads APIは写真をファイルで受け取れず、「公開されたURL」でしか指定できません。
そのため、ここに置いた写真が次のURLで公開され、Threadsがそれを取りに来ます。

```
https://raw.githubusercontent.com/kanakao-nakatsuka/kikko-images/main/写真/ファイル名
```
